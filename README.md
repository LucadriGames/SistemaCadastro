# Sistema de Cadastro em Java

Sistema de cadastro desenvolvido em Java como projeto de prática de Programação Orientada a Objetos.

## Funcionalidades

- Cadastrar pessoas
- Listar pessoas
- Buscar pessoas pelo nome
- Editar pessoas
- Remover pessoas
- Contar pessoas cadastradas

## Tecnologias

- Java 21
- Eclipse IDE
- JOptionPane
- ArrayList

## Conceitos praticados

- Classes e objetos
- Construtores
- Encapsulamento
- Getters e setters
- Métodos
- ArrayList
- For-each
- Estruturas condicionais
- Estruturas de repetição
- CRUD

## Como executar

1. Clone o repositório.
2. Abra o projeto no Eclipse.
3. Execute a classe `Principal.java`.
4. Utilize o menu para cadastrar, consultar, editar e remover pessoas.
